# Python: AI Playground, Level 1
Generative AI tools can greatly enhance your coding abilities. In this open-ended, hands-on workshop, participants will experiment with AI to build useful, creative, and custom-tailored projects.

Participants will explore prompting, iteration, and troubleshooting while creating a "proof-of-concept" live product. Bring your own idea, or use the instructor-led project for inspiration and experimentation. Expect to try things, break things, and learn what works!

**Learning Objectives**
- Introduction to Generative AI and Gemini
- Writing better prompts
- Creating bespoke solutions with AI
- Iterating and testing AI-generated results
- Building "proof-of-concept" projects with AI

**Prerequisites**

Having some basic programming knowledge is encouraged, but not required. No prior experience with AI is required. Participants should have access to a GitHub account.
