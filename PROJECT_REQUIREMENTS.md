# Project Requirements

## Business Requirements
The overall goal and value of the project, such as what problem it solves and why it matters to the organization or client.

## User Requirements
User requirements describe what the end user needs the system to do in practical, everyday terms.

## Software Requirements
Software requirements define the technical conditions and constraints the system must meet, including the tools, languages, and rules needed to build and run it.

- Python 3
- Flask
- SQLite
- HTML and CSS
- NO JavaScript
- Do not use React, Node.js, or any JavaScript framework
